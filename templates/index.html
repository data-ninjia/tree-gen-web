Structure Tree Generator
How to use Structure Tree Generator

What does this tool do?

Structure Tree Generator takes an Excel file with a list of system components and turns it into a professional PDF diagram — a tree structure that shows how everything is organized across multiple sites or installations.

Preparing your Excel file

Your file must have at least 3 columns:

ColumnWhat goes hereExample values
Main SystemThe site or installation codeG001, T001, W102
System / SubsystemThe system or subsystem codeMQA, MQA01, MSE10
DescriptionA short name for each itemPhotovoltaic Generator System 1

Main System column

  • Format: prefix + 1 letter followed by 3 digits (or without prefix also applicable) — =G001, =T001, =W102
  • Each unique code is treated as a separate installation
  • Add one row per installation where the System/Subsystem column is empty — this is the description row for that installation

System / Subsystem column

  • System headers — letters only, 3 characters: MQA, MSE, AHA — these are group titles
  • Subsystems — 3 letters + exactly 2 digits: MQA01, MSE10 — these are the individual items
  • Always add a System header row before the subsystems that belong to it, in every installation

Description column

  • Keep descriptions under 60 characters — longer ones will be cut off in the PDF
💡 Example of a correctly structured file:

=G001 |      | Photovoltaic Field 1
=G001 | MQA   | Photovoltaic Generator System
=G001 | MQA01 | Photovoltaic Generator System 1
=G001 | MQA02 | Photovoltaic Generator System 2
=G002 |      | Photovoltaic Field 2
=G002 | MQA   | Photovoltaic Generator System
=G002 | MQA01 | Photovoltaic Generator System 1

Step-by-step

Step 1 — Upload your file

Drag and drop your .xlsx file onto the upload area, or click Browse file.

Step 2 — Map your columns

A window will appear showing all columns with example values. Assign each column a role using the dropdown. The tool tries to detect them automatically — check that the assignments look correct before clicking Confirm.

Step 3 — Review the structure

The left panel shows all Main Systems found. Click any to see its systems and subsystems. Each row shows the code, description, coverage (e.g. 27/28) and status — STATIC if present in all installations, OPTIONAL if only in some.

Tick UNGROUP on any grouped row to expand it into individual codes in the PDF.

Step 4 — Generate PDF

Click Generate PDF in the top right. The file downloads automatically.

Understanding the PDF

  • Overview page — a grid of cards, one per Main System. Click any card to jump to its tree.
  • Tree pages — hierarchy diagram with Main System at top, Systems in the middle, Subsystems below. Items marked * are OPTIONAL.
  • Matrix page — appears if there are OPTIONAL subsystems. Shows a table with installations as columns and optional subsystems as rows, with ✕ where present.

Common problems

"Missing Main System column" — assign the correct column to Main System in the mapper.
"Subsystem has no System header" warning — a subsystem like MQA01 exists in an installation but has no MQA header row in that same installation. Add the missing header row.
Descriptions cut off in PDF — shorten them to under 60 characters.
